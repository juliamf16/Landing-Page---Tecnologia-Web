Grupo 10 - Hugo Raposo, Julia Freitas, Sara Freire
No projeto PEI1 é pedido para ser criado uma landing page de uma web-page para uma
centro académica clínico fictício nos açores.

Na etapa de design:

• Wireframes - É possível ver vários tipos de organização, e acabamos por usar um
deles, em que a landing page possui 2 cabeçalhos simples e não utiliza menus tão
complexos. Além disso, mantivemos as localizações do logotipo e do nome da
clínica, bem como as informações de rodapé.

• Mockups - Ficou igual com o website final, visto que o mesmo serviu de base para
o programa de html.

A landing page final ficou com o tom de azul representativo da universidade, uma
organização simples para facilitar a sua navegação. Relativamente à acessibilidade, por
exemplo todas as imagens têm um elemento alt com as designações de imagens para
caso não apareça a imagem e tivemos em conta pessoas com dificuldades visuais e
utilizamos elementos semânticos para que consigam utilizar o software de leitura de voz
para a navegação do site. Além disso, foi usado keyframes para animações com imagens
e certas caixas de texto, para o site ficar mais dinâmico. Finalmente, foi feito com que o
cabeçalho ficasse sempre visível para o utilizador, caso o mesmo deseje ir para diferentes
secções do website.
